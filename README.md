# 🚀 CareerPilot AI

**Your AI-powered career development assistant.**

CareerPilot AI helps students and job seekers identify skill gaps, prepare for technical interviews, build personalized learning roadmaps, and track their career progress.

## ✨ Features

- **Resume Analyzer:** Extracts candidate skills, education, projects, and experience from PDF resumes.
- **Skill Gap Analysis:** Compares candidate skills against target job requirements.
- **Adaptive Learning Roadmap:** Generates personalized weekly learning plans based on skill gaps and interview feedback.
- **Portfolio Project Recommendations:** Suggests practical projects to strengthen missing skills.
- **AI Mock Interviews:** Generates technical interview questions and evaluates answers with scores and actionable feedback.
- **Application Tracker:** Tracks job applications and responses.
- **Progress Dashboard:** Displays learning progress and career preparation statistics.

## 🛠️ Technology Stack

- Python
- Streamlit
- Groq API
- SQLite
- PyMuPDF
- Pandas
- Plotly

## ⚙️ Installation

1. Clone the repository:

   ```bash
   git clone YOUR_GITHUB_REPOSITORY_URL
   cd CareerPilotAI
   ```

2. Install dependencies:

   ```bash
   pip install -r requirements.txt
   ```

3. Create a `.env` file in the project directory:

   ```env
   GROQ_API_KEY=your_groq_api_key
   ```

4. Run the application:

   ```bash
   streamlit run app.py
   ```

## 🔐 Security

Keep API keys and personal candidate information private. Never commit `.env` files or personal databases to GitHub.
